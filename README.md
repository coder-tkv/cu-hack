# cu-hack — разбор сессий кодинг-агента

Мы проектируем сайт по кейсу «Что наделал агент»: загружаем лог, находим проверяемые признаки неэффективной работы и получаем рекомендации для следующей сессии.

## Документы команды

1. [Что мы делаем и зачем — простыми словами](docs/01-problema-prostymi-slovami.md). Начинаем здесь: проблема, требования, пример, устройство сайта и ML без сложных терминов.
2. [Подробная архитектура и ML](docs/02-architecture-and-ml.md). Стек, парсер, метрики, модель, промпт, формат запросов и ответов, API, хранение, структура папок, проверки и этапы реализации.
3. [Бриф для дизайнера](docs/03-design-brief.md). Экраны, данные на них, обязательные состояния и план работы на 4 часа.

Документы написаны от лица команды. Это план будущей реализации; приложение пока не создано. Визуальный дизайн разрабатывает наш дизайнер.

Дизайн:
https://figma.com/file/qnKm1hYY80gGA6UknLHpRS?locale=en&type=design

Основная цепочка: **лог → парсер → факты из кода → объяснение моделью → проверка → отчёт и предлагаемые правила**.
